## Grupos

Los usuarios pueden crear grupos e invitar a otros usuarios a unirse.

- **Creación**: un usuario crea un grupo (probablemente con nombre, y más adelante
  descripción/imagen/privacidad — a definir).
- **Búsqueda de usuarios a invitar**: campo de búsqueda por **nick** o **email**. Si se
  encuentra una coincidencia, se envía una invitación.
- **Notificación de invitación**: se envía un **email** al usuario invitado.
- **Badge de invitaciones pendientes**: el usuario invitado ve un indicador (badge) en la
  sección "Grupos" señalando que tiene invitaciones pendientes.
- **Aceptación**: si el usuario acepta la invitación, se añade como miembro del grupo.

Preguntas abiertas (no resueltas aún, anotar aquí decisiones cuando se tomen):
- ¿Se puede rechazar una invitación explícitamente, o solo ignorarla?
- ¿Roles dentro del grupo (creador/admin vs miembro)?
- ¿Un grupo tiene contenido propio (publicaciones visibles solo para el grupo) o es solo un
  agrupamiento de usuarios?
- ¿Límite de miembros por grupo?
